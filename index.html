EvalSim

Closed-Loop Simulation-Evaluation Platform  ·  Waymo Open Motion Dataset · Waymax · JAX · Python

An evaluation platform that decides whether a traffic simulator is realistic, reactive, diverse, physically feasible, and useful for closed-loop autonomous-driving testing — instead of collapsing simulation quality into one leaderboard number.

What are we doing here?

The contribution is the evaluation methodology, not the simulator. We use simple baselines (log-replay, constant-velocity, IDM) with deliberately different failure modes, and invest all the engineering in the system around them.

The core problem

A simulator can ace one metric while being unusable for closed-loop eval. Log-replay matches real trajectories but can't react when the ego deviates. A rule-based agent reacts but turns unrealistically defensive. A stochastic model looks diverse by being noisy and infeasible. EvalSim reveals these differences instead of hiding them.

The key design move

Contract-first, substrate-agnostic. A frozen Scenario contract has two producers: a synthetic generator (Mac) and a Waymax/WOMD loader (Cloud). Everything downstream reads only the contract — so ~95% is built & validated on a Mac CPU, and the Waymax stage is quarantined to one short cloud session.
